# 🚲 鹈鹕骑行记 · 兜风小动画

一只戴着草帽、系着红围巾的鹈鹕，骑着薄荷绿复古单车出门兜风。
纯 **SVG + 原生 JavaScript** 单文件实现，零图片素材、零依赖、零构建。

**线上地址：** https://yjj0339.github.io/tihu-ride/

手机扫码打开：

![二维码](qr-live.png)

## 玩法

- **速度滑杆**：控制骑行快慢——蹬踏频率、车轮转速、风景后退、围巾飘动全都跟着速度走
- **🔔 铃铛**：叮铃铃~（WebAudio 真铃声，车把上的铃铛还会抖动）
- **☀️ 场景切换**：清晨 / 正午 / 黄昏，全部是明亮浅色配色
- **🌸 风景切换**：花田 / 小镇 / 海边三种风景自动轮换，也可手动切换
- **里程碑**：每骑满 1 km 弹出庆祝小气泡（右上角有里程表）
- 快捷键：`空格` 暂停/继续，`B` 按铃铛

## 技术要点

- 单文件 `index.html`，SVG 分层绘制：天空→云→远山→中景物件→路面→车与鹈鹕→近景草花
- 鹈鹕双腿为**两段式 IK 解算**，脚掌实时锁定在旋转的脚踏上
- 山丘用整数周期正弦曲线生成，无缝循环滚动；四层视差（远山/中景/路面/近景）
- 场景切换用补间引擎渐变十几处颜色（天空、山、海、路面、草地、太阳、云）
- 小细节：眨眼、扇翅膀、围巾/帽带飘动、车筐里的鱼摆尾、海面闪光、帆船、飞鸟、花瓣、速度线
